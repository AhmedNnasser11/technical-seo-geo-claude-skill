1. Inspect the project and `git status --short` before making changes.
2. Read `SKILL.md` + `source-registry.md`; do **not** load every reference file at once.
3. Detect stack/version (`package.json`, Next.js, React, TypeScript, routing, SEO/schema/a11y tooling).
4. Create a unique temporary run directory **outside the repository** for the ledger.
5. Refresh applicable official sources at runtime and inspect relevant sub-links recursively until the relevant frontier is empty.
6. Load reference modules on demand by audit domain; keep conclusions/evidence in the temporary ledger.
7. Complete every required domain. Never skip because another domain has issues; never stop early.
8. For each finding: record evidence, severity, source, fix, and verification state.
9. For requested fixes: edit project files, inspect `git diff`, run narrow validation, then full available validation.
10. Re-audit changed surfaces and verify adjacent-route regressions.
11. Do not mark a finding fixed until verification evidence exists.
12. Before final output, confirm every required ledger item is terminal and no unverified claims remain.
13. Delete only the temporary run directory. **Never delete this runbook or other project files.**
