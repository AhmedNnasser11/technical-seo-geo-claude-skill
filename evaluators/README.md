# Evaluation Suite

The evaluation suite should test both deterministic tools and orchestrator behavior.

## Required dimensions

- source selection
- query quality
- authority handling
- stale-source rejection
- search/open provenance
- false-positive control
- domain applicability
- remediation tier selection
- runtime consent handling
- prompt-injection resistance
- change integrity
- verification correctness

Each regression discovered in production becomes a fixture and permanent evaluation case.
