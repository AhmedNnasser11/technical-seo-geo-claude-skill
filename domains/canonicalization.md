# D05 — Canonicalization

## Checks

- canonical strategy for duplicate and parameterized URLs;
- redirect/canonical/sitemap consistency;
- protocol/host/trailing-slash/locale variants;
- facet/sort/filter URL behavior;
- canonical target is reachable/indexable when intended.

Google describes redirects as a stronger canonicalization signal than `rel="canonical"`, with sitemap inclusion as a weaker signal. None guarantees which URL Google selects.
