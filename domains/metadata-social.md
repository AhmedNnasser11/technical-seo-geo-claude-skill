# D04 — Metadata & Social

## Checks

- unique, descriptive titles and descriptions;
- route-appropriate robots directives;
- coherent Open Graph and social metadata;
- canonical metadata where required by the URL strategy;
- localization metadata where applicable;
- no conflicting route/layout metadata.

## Next.js

Prefer version-matched Metadata API and file conventions. `metadata` and `generateMetadata` are supported in Server Components; file-based metadata includes robots/sitemap and social-image conventions.
