# D03 — Accessibility

## Source basis

Use current W3C/WAI guidance, with WCAG 2.2 as the normative baseline unless the project has a stricter contractual target.

## Checks

- accessible names for controls and images;
- keyboard operability;
- focus order and visibility;
- dialog/menu/tab/listbox behavior;
- labels, errors, instructions, and form semantics;
- ARIA only where appropriate;
- color/contrast checks when tooling permits;
- reduced motion and touch/pointer considerations where relevant;
- status/state changes exposed accessibly.

## Conformance discipline

Do not claim full WCAG conformance from static inspection alone. Interaction claims need runtime evidence where behavior cannot be established from source.
