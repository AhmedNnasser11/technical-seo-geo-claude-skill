# D06 — Structured Data

## Checks

1. Identify the page/entity model.
2. Verify Schema.org vocabulary exists.
3. Verify Google feature eligibility separately from Schema.org vocabulary.
4. Validate syntax and required properties for the applicable feature.
5. Check every material claim against visible page content.
6. Detect duplicate/conflicting JSON-LD.
7. Check version/deprecation/feature changes before recommending markup.

Schema.org's latest stable release is currently 30.0 (published 2026-03-19); the runtime source check must still confirm the current release at audit time.

For ecommerce, distinguish product snippets from merchant listings and inspect the current Google requirements.

Never invent an "AI schema" requirement: Google explicitly states there is no special schema.org structured data required for AI Overviews/AI Mode.
