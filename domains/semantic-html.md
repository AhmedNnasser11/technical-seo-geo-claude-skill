# D02 — Semantic HTML

## Checks

- Appropriate document landmarks.
- Logical heading hierarchy for content structure.
- Native elements preferred over unnecessary ARIA role recreation.
- Lists, tables, figures, labels, buttons, and links reflect their actual semantics.
- Semantic structure supports accessible names and machine-retrievable content.

## Evidence

Static source evidence can prove markup choices. Interaction-dependent claims require approved runtime evidence.

## Pass

No material semantic defect supported by applicable W3C guidance and project evidence.
